# 产品规格

## 目标

轻记服务一个用户在多个桌面和浏览器终端上的个人知识管理。它优先解决：

1. 笔记以普通 Markdown 文件长期保存，不被数据库或厂商锁定。
2. 多端离线可用，恢复联网后可靠收敛，不静默覆盖内容。
3. 中文搜索、编辑和导航在数万篇笔记范围内保持可用。
4. 一个 Docker Compose 项目即可部署、升级、备份和恢复。

## 核心用例

- 用户登录后看到最近编辑的笔记，可按目录、标签或收藏筛选。
- 用户创建、移动、重命名、编辑和删除笔记，修改自动保存。
- 离线时修改进入本地 outbox；联网后按顺序推送并拉取远端变化。
- 两个终端从同一修订离线编辑时，服务器保留先到版本，并为后到版本创建冲突副本。
- 用户可以搜索中文标题、正文、标签和路径，并跳转到匹配上下文。
- 用户停止服务后，仍可用任意文本编辑器读取 Markdown 与附件。

## MVP 边界

包含 Web/PWA（桌面壳为实验代码）、单账号认证、Markdown 编辑与预览、附件、内部链接、反向
链接、中文搜索、收藏、最近、标签、回收站、同步、导出和重扫。

不包含移动原生端、多人协作、分享权限、插件系统、图谱、白板、OCR、网页剪藏、
CRDT、端到端加密、Git/WebDAV 同步或第三方编辑器实时双向写入。

## 非功能要求

- 数据安全：删除进入回收站；冲突生成副本；任何同步异常不得静默丢弃正文。
- 可恢复性：当前索引可从 vault 重建；历史版本和会话等不能，仅保存在 SQLite。
- 可移植性：路径和 frontmatter 使用 UTF-8；附件使用相对链接。
- 性能目标：性能需按数据规模实测，当前搜索使用内存扫描；常规增量
  同步只传输游标后的事件。
- 可访问性：主要操作可键盘完成，交互控件有可读标签，颜色不是唯一状态信号。

## 视觉与交互

视觉主张：安静的纸墨工作台，以温润纸色、炭黑和单一朱砂色建立层级；所有装饰都
服务于阅读和长时间写作。

工作区分为目录导航、主编辑器和上下文检查器三部分。动效仅用于面板切换、保存状态
和搜索跳转，保持快速、克制，并尊重 `prefers-reduced-motion`。
