## 发布方式

旧私有工作仓库保留历史供回查。公开仓库应从审核后的当前源码建立一个新的初始提交，仅包含跟踪的源文件；不带 `.git` 旧历史、运行数据、密钥、迁移报告、私人截图、构建产物或安装依赖。

发布目录根 README 包含启动与限制说明。推送前在该目录确认 `git status` 干净，运行 `git log` 应只有开源初始提交，再添加自己的 GitHub remote。不要在原私有仓库直接公开全部历史。仓库发布后启用私密漏洞报告并检查首次 CI 结果。

## 明确限制

S3 快照不含历史数据库；完整冷备须停服务复制整个数据目录。离线附件队列、多人权限、CRDT、端到端加密和共享目录多进程锁未实现。搜索为内存扫描，JSON/附件默认大小上限仍存在，编辑器资源块有包体积告警。Tauri 壳未验证成品构建。公网 HTTPS、真实服务商 S3 恢复与费用需部署者在自己的独立测试目标验证。

这些边界在 README、SECURITY 与相关协议文档中公开说明。此次测试未对生产数据执行恢复或清理，也未将本轮修改部署到正式实例。
