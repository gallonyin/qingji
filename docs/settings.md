# 应用设置

登录后点击左下角账号区的齿轮。手机上先打开菜单；空笔记库同样有菜单入口。设置对话框提供外观、S3 备份和关于三个分类，正文独立滚动；关闭未保存修改会确认。

## 外观与项目入口

名称和图片 Logo 保存后实时更新左上角、登录页和浏览器标题/图标。选择 PNG/JPEG/WebP 原图后，浏览器会自动缩放压缩到最长边 512px、最终不超过 512 KiB；服务端仍会做同样的最终大小和格式校验，不接受 SVG 或外部图片地址。未设置图片时暂时显示内置占位标记；可以移除图片或恢复默认外观。PWA manifest 使用保存的名称与图标，已安装应用是否刷新由浏览器决定。

品牌信息是公开的，可在登录前显示；浏览器只缓存品牌信息用于离线显示。账号区与关于页的 GitHub 地址为 https://github.com/gallonyin/qingji，仓库创建后沿用此地址。

## 可选 S3 配置

不开启 S3 仍可使用所有笔记功能。设置可修改 Endpoint、Region、桶、前缀、密钥、Path-style、服务端加密、自动备份间隔及快照保留数量。首次运行兼容已有 S3_BACKUP_* 环境变量；首次保存后，以数据目录 settings.json 为准，不再被环境变量覆盖。密码与访问 origin 仍由环境变量配置。

密钥保存在服务端 settings.json，文件权限为 0600。GET 配置不返回 Access Key 或 Secret Key，只返回是否已保存的标记；留空保持原密钥。清除密钥需要选中明确选项，并关闭备份。完整冷备包含此文件，保管与笔记库同样重要；S3 内容快照不包含此配置。

保存配置实时生效。当前备份或恢复任务未结束、或恢复保护未解除时，不允许修改 S3；外观修改不切换存储。配置使用 revision 检查并发，旧窗口不能静默覆盖新设置。切换桶或前缀隔离增量缓存并建立新基线，旧目标不自动删除。开启自动备份可能按规则发起首次完整备份，关闭开关不删除已存在的云端对象。

## 测试连接

“测试 S3 连接”使用当前未保存的表单；空密钥可以沿用服务端已保存值。先列举备份前缀，再在 .connection-test/<随机ID> 写入 32 字节对象、读取比对并删除。测试不修改快照或 latest，不发起备份，也不保存配置。

主测试有 20 秒超时，清理有独立 5 秒限时，且每 IP 每分钟最多 5 次。失败会尝试清理；清理失败不报成功，并提示检查前缀下 .connection-test。错误不返回 SDK 原始消息或密钥。结构化日志 settings.updated、settings.s3_test 仅记录状态、版本、阶段和耗时，不包含密钥或正文。

自动化测试覆盖持久化、权限与密钥脱敏、并发更新、恢复保护、后台任务互斥、输入校验、真实 SDK 到本地 HTTP S3 兼容接口的签名请求与读写删除。服务商是否支持所选加密、寻址和权限，应通过自己的测试按钮确认。
