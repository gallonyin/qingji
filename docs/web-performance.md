# 网页性能与缓存

前端按目录元数据导航，正文按需加载，内存目录索引由 Worker 构建；树中的笔记按批展开。预览使用 memo，图片延迟加载和异步解码。编辑器、Markdown、存储和 React 依赖拆分为静态资源块。

Nginx 为 JSON、JS、CSS 等启用 gzip。带哈希的 /assets/ 资源长期缓存，HTML、manifest 和 Service Worker 重新验证。Service Worker 仅缓存应用壳和静态资源，不缓存 API 或私有附件；只在安全上下文工作，离线可用范围取决于之前成功加载的内容。

远端延迟主要影响未缓存正文、附件和首次目录拉取。HTTPS 本身不会保证更低延迟，但提供安全上下文，并使具备 HTTP/2 的前置代理能够复用连接；是否更快仍需实测。

当前全文搜索使用服务端内存扫描，超大单篇文件会增加解析与内存开销。没有 CDN、服务端全文索引、虚拟化全列表或无限规模保证。构建中的编辑器包体积告警需结合实际加载耗时判断。

测量应记录浏览器版本、网络往返延迟、缓存冷热、笔记规模和窗口宽度；使用隔离测试数据，避免公开真实文章标题、正文、部署地址或生产日志。
